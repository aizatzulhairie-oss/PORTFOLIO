This folder is designated for your custom images:
- /public/images/profile/        -> Your personal portrait photos
- /public/images/education/      -> Campus photos, academic certificates
- /public/images/internships/    -> Insulet and Vocational College photos
- /public/images/logos/          -> University, school, company and club logos
- /public/images/certifications/ -> Certification provider logos & badges
- /public/images/volunteering/   -> Extracurricular activity photographs
- /public/images/projects/       -> Engineering drawings, CAD models, dashboard screenshots

See src/data/portfolioImages.ts to configure which image file maps to each placeholder.
Or click on any placeholder in the website to test uploading live in the browser!
